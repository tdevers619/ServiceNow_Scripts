# Post Incident Script (Powershell)

Important Notes
Column Names: Make sure the column names in $row.Description and $row.'Short Description' match the column headers in your Excel file. Adjust them if necessary.

Security: Avoid hardcoding sensitive information like credentials in scripts for production use. Consider using secure credential storage or environment variables.

SSL Verification: Ensure SSL verification is enabled in production environments.

By adjusting the script to match your specific Excel file and data needs, you can efficiently import spreadsheet data into ServiceNow incidents.
