# ServiceNow Incident/Task Creator via PowerShell

This PowerShell script allows you to create an incident or task in ServiceNow by using the REST API. The script reads ServiceNow instance details and user credentials from a configuration file to keep your sensitive data separate.

## Requirements

- PowerShell 5.1 or higher
- A valid ServiceNow instance and API credentials
- Internet access to connect to your ServiceNow instance
